Talpinimas GitHub Pages su subdomenu

                

                
            

            

                
Ši aplikacija parašyta viename index.html faile, todėl jai nereikia jokio serverio ar duomenų bazės.

                

                    
1. Įkėlimas į GitHub:

                    
    
                        
  • Sukurkite naują viešą (Public) GitHub repozitoriją, pvz., saskaita.
    • 
                        
  • Įkelkite šį failą pavadinimu index.html.
    • 
                        
  • Eikite į Settings → Pages ir prie Branch pasirinkite main (Save).
    • 
                    

                

                

                    
2. Nuosavo subdomeno prijungimas (pvz., saskaita.manodomenas.lt):

                    
    
                        
  • Savo domeno DNS valdyme sukurkite CNAME įrašą:
    • 
                        
  • Name / Host: saskaita (arba kitas norimas subdomenas)
    • 
                        
  • Target / Value: jusu-github-vardas.github.io
    • 
                        
  • GitHub repozitorijoje (Settings → Pages → Custom domain) įrašykite saskaita.manodomenas.lt, išsaugokite ir pažymėkite Enforce HTTPS.
    •
